# L2 - Print Something Small

Download from batWhistleTCF.stl from [https://www.printables.com/model/1451165-halloween-bat-whistle-and-key-chain/files](https://www.printables.com/model/1451165-halloween-bat-whistle-and-key-chain/files).
I was struggling to find something that didn't have holes or overhangs in it, and this bat whistle was the first 3D printable object that I liked and satisfied the requirements. I also thought it would be a cool item to show off as my first 3D print.
